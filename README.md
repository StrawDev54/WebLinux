# WebLinux

Mini système Linux simulé dans le navigateur : bureau, terminal, gestionnaire de fenêtres, comptes utilisateur et administration simulée.

## Utiliser le projet

Ouvre `index.html` directement ou active GitHub Pages sur la branche `main`, dossier `/ (root)`.

## Comptes de démonstration

| Compte | Mot de passe | Droits |
|---|---|---|
| `user` | `user123` | utilisateur |
| `admin` | `admin123` | administration simulée |

## Commandes utiles

- `help`, `ls`, `pwd`, `whoami`, `date`, `clear`
- `neofetch`, `users`
- `sudo useradd NOM`
- `sudo passwd NOM`

> Cette authentification est uniquement destinée à une démonstration dans le navigateur. Elle ne constitue pas une sécurité réelle.
